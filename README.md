# Peterlyn's Paradise Resort

Hotel booking system with a Firebase/Firestore frontend and a PHP/MySQL fallback.

## Run locally

Firebase app (recommended):

```bash
node server.mjs
```

Open [http://localhost:3000](http://localhost:3000).

XAMPP: [http://localhost/paradiseresort/](http://localhost/paradiseresort/) redirects to the same app. The legacy PHP pages are at `index.php?legacy=1`.

Local demo login: `admin@paradise.local` / `admin123`
